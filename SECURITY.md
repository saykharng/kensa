# Security policy

Kensa is a local app. A vulnerability here can expose source code, review comments, or GitHub access on the machine where it runs.

## Reporting

Please report a vulnerability in private. Do not open a public issue, pull request, or discussion for it.

- GitHub private advisory: <https://github.com/saykharng/kensa/security/advisories/new>
- Email: saykharng.gyanwali@gmail.com

Include what is affected, how to reproduce it, and the impact you expect. A maintainer will acknowledge the report and agree on a fix before any public write-up.

## Supported versions

No release has shipped yet. Reports against `main` are in scope.

## What stays on your machine

The app is not supposed to upload review notes, repository contents, or GitHub tokens. A bug that does that is a security bug. File those through the contacts above.
